## ГДЕ
Пять экранов Settings: Preferences → OneAgent default mode; Updates → OneAgent updates, Update windows, ActiveGate updates; Preferences → Network security.
Routes (`/ui/settings/`): builtin:deployment.oneagent.default-mode, builtin:deployment.oneagent.updates, builtin:deployment.management.update-windows, builtin:deployment.activegate.updates, builtin:activegate-token.

## ЗАЧЕМ
Тема про практику: куда кликнуть, чтобы задать режим агента, обновить парк и шлюзы, задать окно обслуживания, держать политику токенов.
Архитектурная теория была в Теме 1, здесь управление ею.

## ЦИФРЫ
- Лицензия: Full Stack до 1.0 HU за 16 GiB (меньше памяти: дробные ступени 0.10 / 0.25 / 0.50), далее +1 HU за каждые 16 GiB; Infrastructure 0.3 HU @ 16 GiB.
- Окно обновления агентов: рекомендованный минимум 3 часа, оптимум 4–5.
- В рабочей инсталляции обычно 2–4 Environment ActiveGate.
- Токен: три части `<prefix>.<24-символьный public>.<64-символьный secret>`; префикс dt0s01 это API tokens.
- Rolling-обновление кластера: UI может «мигнуть» на 10–30 секунд, данные не теряются, буферизуются в ActiveGate.

## ЕСЛИ→ТО
- ЕСЛИ при установке передан ключ `--set-monitoring-mode=infra-only` → страница OneAgent default mode игнорируется, агент стартует в режиме из ключа.
- ЕСЛИ окно короткое (1 час) на группе с десятками хостов → цикл не завершается, версия остаётся между старой и новой до следующего окна.
- ЕСЛИ автообновить все шлюзы одновременно → агенты на время перезапуска dtgateway теряют связь, и инцидент в этот момент Davis AI не обнаружит.
- ЕСЛИ уведомления об истечении токенов выключены → токен истечёт молча и всплывёт ошибкой при регистрации нового шлюза.

## ВОПРОСЫ АУДИТОРИИ
- «OneAgent updates это тумблер автообновления?» Ответ: нет, страница задаёт целевую версию и показывает статус парка; режим обновления лежит в Settings → Host groups.
- «Токен ActiveGate истёк: работающие шлюзы отвалятся?» Ответ: нет, токен нужен только в момент регистрации, дальше шлюз ходит по постоянному сервисному ключу.
- «Почему в production выбирают Previous stable, а не Latest?» Ответ: сборка уже несколько недель проверена другими, компромисс между свежестью и надёжностью.
